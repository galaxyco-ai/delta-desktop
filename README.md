# delta-desktop

Windows desktop shell (Tauri v2) for Delta at https://delta.galaxyco.ai.

- App source: [`desktop/`](desktop/) (see [desktop/README.md](desktop/README.md))
- CI and releases: [`.github/workflows/desktop.yml`](.github/workflows/desktop.yml)
- Downloads: [latest release](https://github.com/galaxyco-ai/delta-desktop/releases/latest)

Installers are not Authenticode signed yet, so SmartScreen will warn on first
run. Use More info, then Run anyway.
